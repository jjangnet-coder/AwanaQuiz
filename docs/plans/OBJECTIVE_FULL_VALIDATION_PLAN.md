# [수정계획서 4차] 객관식 누락 방지 완전성 검증(Validation) 및 미완료 하이라이트

## 1. 피드백 분석 및 현장 규칙 정의
* **사용자 제안:** "객관식의 경우에는 모든 칸이 채워지지 않으면 제출이 안 되어야 하는 게 맞지 않나요?"
* **현장 규칙 확인:**
  - **전적으로 옳으신 지적입니다!**
  - **객관식(1~8번 문항):** 모든 학생이 매 문항마다 정답(`O`) 또는 오답(`X`)을 반드시 판정받아야 하므로, **빈칸(미응답)이 남아있는 것은 기록관의 입력 누락(실수)**입니다.
  - **스피드 퀴즈(1~10번 문항):** 문항당 단 1명만 정답을 맞히고 조기 퀴즈아웃/파울아웃된 학생은 뒷 문항이 잠기므로 빈칸이 자연스럽게 발생합니다.
  - 따라서 **객관식 퀴즈에 한하여 모든 칸(`학생수 × 8문항`)이 채워졌는지 엄격한 완전성 검증(Validation)**을 적용하는 것이 맞습니다.

---

## 2. 세부 구현 계획

### ① 객관식 제출 시 빈칸 누락 완전성 검증 (`Validation`)
* 객관식 세션에서 `[점수 제출]` 버튼을 클릭했을 때:
  1. 전체 학생의 1~8번 셀을 전수 조사하여 **빈칸(`""`)이 1개라도 존재하는지 검사**.
  2. 빈칸이 발견되면 중앙 서버 전송을 즉시 중단하고 **커스텀 모달 팝업** 표출:
     - 제목: **`⚠️ 채점 누락 안내`**
     - 내용: **`아직 채점되지 않은 빈칸이 총 N개 있습니다.\n모든 문항을 O 또는 X로 채점 완료한 후 제출해 주세요.`**
  3. **누락 셀 시각적 하이라이트:**
     - 채점이 누락된 빈 셀들에 **붉은색 점선 테두리 및 부드러운 깜빡임 효과**를 부여하여 기록관이 즉시 찾아서 누를 수 있도록 유도. (셀 클릭 시 하이라이트 자동 해제)

### ② 3단계 버튼 상태 머신 세분화
* **상태 1: `입력 대기` (점수 0개 입력 시)**
  - 버튼: 파란색 `📤 [N교시] 점수 제출` (클릭 시 "채점을 먼저 진행해 주세요" 안내)
* **상태 2: `채점 중 (미완료 또는 미제출)` (O/X 입력 중)**
  - 빈칸이 남아있는 경우: 주황색 `📤 [N교시] 점수 제출 (작성 중)`
  - 전원 모든 칸 채점 완료 시: 눈에 띄는 진한 주황색 `📤 [N교시] 점수 최종 제출 (완료)`
* **상태 3: `제출 완료` (시트 전송 성공 후)**
  - 버튼: 녹색 `✅ [N교시] 제출 완료`
