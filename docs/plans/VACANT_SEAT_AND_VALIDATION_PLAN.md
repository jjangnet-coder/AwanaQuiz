# [수정계획서 5차] 공석(결번) 고정 표시 및 객관식 누락 방지 완전성 검증

## 1. 현장 문제점 분석 (마스터 핵심 지적)
* **문제 현상:** 올려주신 캡처 화면([스팍스3 / 1교시 / 행글라이더 1학년 3조])을 보면 **10번 다음 바로 12번**이 나옵니다 (11번 결번/취소).
* **위험성:** 현장 시험장의 단원들은 번호표(1번, 2번... 10번, 11번[빈자리], 12번...) 순서대로 앉아 있습니다. 만약 화면에서 11번이 빠져서 12번이 11번째 줄에 위치하면, **기록관이 번호 착오로 인해 12번 이하 학생들의 점수를 한 칸씩 위로 밀려 쓰는 치명적인 현장 사고**가 발생합니다.
* **원칙:** **번호(NO)는 1번부터 해당 조의 마지막 번호까지 절대 건너뜀 없이 무조건 연속으로 표출**되어야 합니다!

---

## 2. 세부 구현 계획

### ① 연속 번호 보장 및 [공석] 슬롯 처리
1. **연속 번호 슬롯 생성:**
   - 해당 조의 최소 번호(보통 1번)부터 최대 번호(예: 18번)까지 루프를 돌며, 명단에 없는 번호(예: 11번)는 **`공석(Empty Slot)` 행**을 자동으로 삽입.
2. **공석 행 UI 스타일링:**
   - `NO`: `11` (번호 정상 표시)
   - `핸드북`: `-`
   - `조`: `-`
   - `교회명`: `-`
   - `이름`: `<span class="badge-vacant">공석</span>` (차분한 회색 배지)
   - `1~8/10번 문항 셀`: `class="quiz-cell vacant"` ➔ 연한 회색 배경, 클릭 불가, 커서 금지(`not-allowed`)
   - `O수`, `X수`, `총점`: `-`
3. **완전한 채점 대상 제외:**
   - 객관식 문제 번호 클릭(전원 정답 `O`) 시에도 **공석 행은 대상에서 자동 제외**.

---

### ② 객관식 누락 방지 완전성 검증 (`Validation`) 연동
* **제출 버튼 클릭 시 검증 로직:**
  1. **실제 출석 단원들만 대상**으로 1~8번 문항에 빈칸(`""`)이 있는지 검사. (**공석 행은 검사 대상에서 제외**)
  2. 출석 단원 중 빈칸이 1개라도 남아있으면 중앙 시트 전송을 차단하고 커스텀 모달 표출:
     - **`⚠️ 채점 누락 안내: 아직 채점되지 않은 빈칸이 N개 있습니다. 모든 칸을 채점 완료한 후 제출해 주세요.`**
  3. 누락된 빈 셀들에 **붉은색 하이라이트 깜빡임** 부여 (클릭 시 즉시 해제).

---

### ③ 제출 버튼 3단계 라이프사이클 통합
1. **입력 대기 (초기 상태):**
   - 버튼: **파란색 `📤 [N교시] 점수 제출`** (점수 입력 전에는 "제출 완료"로 오표기되지 않음)
2. **채점 중 / 수정됨 (미완료 또는 미제출):**
   - 빈칸이 남았을 때: **주황색 `📤 [N교시] 점수 제출 (작성 중)`**
   - 전원 채점 완료 시: **진한 주황색 `📤 [N교시] 점수 최종 제출 (완료)`**
3. **제출 성공 시:**
   - 버튼: **녹색 `✅ [N교시] 제출 완료`**
   - (제출 후 다시 점수를 수정하면 즉시 주황색으로 복귀)

---

## 3. 검토 및 승인 요청
공석 행을 밀림 없이 완벽히 배치하여 현장 오기록을 방지하는 완성형 계획서입니다. 검토 후 승인해 주시면 즉시 반영하겠습니다!
