# 본부 관리 포털(`admin/index.html`) 소프트 라이트(Stripe/Toss 스타일) 풀스크린 리디자인 계획서

## 1. 방향 전환: 다크 모드 폐기 → "소프트 라이트 (Soft Editorial Light)"
- 검은 배경 + 흰 글씨(다크 모드)는 한글 표와 숫자가 많은 화면에서 **글자 번짐(Halation)과 눈 피로**를 유발합니다.
- **Stripe 대시보드 / Toss 페이먼츠 콘솔**처럼 눈이 가장 편안하면서도 극도로 세련된 **소프트 라이트(Soft Light)**로 본부 포털 5개 탭 전체를 통일합니다.

---

## 2. 디자인 시스템 (눈 피로 제로 + 고급스러운 입체감)
1. **컬러 팔레트**:
   - **캔버스 배경**: 눈부신 순백 대신 부드러운 쿨 그레이 **`#F4F6F9`**
   - **카드 / 패널**: 깨끗한 **`#FFFFFF`** + 초미세 보더(`rgba(15, 23, 42, 0.06)`) + 부드러운 2단 그림자(`0 1px 2px rgba(15,23,42,0.04), 0 6px 20px -6px rgba(15,23,42,0.06)`)
   - **텍스트**: 순검정 대신 부드러운 차콜 **`#111827`** (제목) / **`#475569`** (본문) / **`#94A3B8`** (보조)
   - **상단 헤더**: 검은 바 폐기 → **깨끗한 화이트 글래스 헤더(`rgba(255,255,255,0.92)`, `backdrop-filter: blur(12px)`)** + 부드러운 탭 필(`#F1F5F9` 트랙 위 화이트 활성 탭)
   - **SPARKS / T&T 공식 컬러**: 두꺼운 원색 줄 대신 **세련된 8px 컬러 도트 + 파스텔 필 배지** (SPARKS: 로즈 레드 `#E11D48` / `#FFF1F2`, T&T: 에메랄드 그린 `#059669` / `#ECFDF5`)

## 3. 화면별 레이아웃 & 컴포넌트 업그레이드
1. **풀스크린 100% 활용 (여백 낭비 제거)**:
   - `.container`: `max-width: 100%;` (좌우 여백 없이 대형 모니터 100% 활용)
   - **3중 박스 탈출**: `#tab-monitor`의 불필요한 바깥 흰 박스를 제거해 `#F4F6F9` 캔버스 위에 4대 요약 카드와 12개 시험장 카드가 바로 떠 있는 개방형 레이아웃 구현 (`min-height: calc(100vh - 96px)`).
2. **대시보드 시각화 고도화**:
   - **상단 4대 요약 카드**: 넉넉한 여백 + `2rem` 굵은 `tabular-nums` 숫자 + 우측 **SVG 원형 도넛 프로그레스 링** 배치.
   - **12개 시험장 카드**: 각 교시 타일의 작은 점(`•••`)을 **3분할 미니 세그먼트 바(`필기 | 오전 | 오후`)**로 교체해 한눈에 진행 상태 파악.
3. **단원 관리 / 필기 채점 / 핸드북별 결과 일괄 정돈**:
   - 단원 관리: 원색 파랑 버튼·이모지 제거 → 깔끔한 아웃라인 고스트 버튼(`수정`, `이동`, `결석`) + 은은한 파스텔 출결 배지.
   - 필기 채점: `height: calc(100vh - 175px)` 고정 풀높이 패널 유지 + 은은한 소프트 블루 입력 열(`#F8FAFF`).
   - 핸드북별 결과(최고득점자): 이름 증발 버그 완전 해결 + 깨끗한 화이트 카드 위 소프트 인디고 칩(`#F1F5F9` 배경 + `#0F172A` 이름 + `#64748B` 교회).
