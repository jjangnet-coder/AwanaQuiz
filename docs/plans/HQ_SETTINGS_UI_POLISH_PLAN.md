# 본부 관리 포털 `대회 설정` UI 다듬기 계획서

## 1. 수정 내역 (`admin/index.html`)

1. **`대회 설정` 버튼 위치 이동 및 안전 간격 확보**:
   - 상단 중앙 탭(`.hq-nav-tabs`)에서 `대회 설정`을 빼고 원래의 5대 업무 탭(`대시보드 · 단원 관리 · 필기 채점 · 시상 명단·인쇄 · 핸드북별 결과`)으로 복원.
   - 우측 액션 영역(`.hq-header-actions`)을 아래 순서로 재배치:
     - `[새로고침]` `[⚙️ 대회 설정]`  **|** *(구분선 + 여유 간격)*  `[대회 점수 초기화]` `[로그아웃]`
   - `대회 설정` 탭 활성화 시 해당 버튼에 활성 강조 스타일(`.active`) 적용.
2. **상단 설정 카드 2종 1:1 동일 너비 & 문구 정리**:
   - `.settings-top-row`를 `grid-template-columns: 1fr 1.35fr;` → **`grid-template-columns: 1fr 1fr;`** 로 동일 너비(50:50) 정렬.
   - 카드 제목 `📊 채점 규칙 & 메달 비율 (숫자 전용)` → **`📊 채점 규칙 & 메달 비율`** 로 불필요한 문구 제거.
3. **`되돌리기` 버튼 문구 직관화**:
   - `되돌리기` → **`변경 취소`** (저장 전 수정하던 내용을 마지막 저장 상태로 되돌리는 기능임을 한눈에 이해할 수 있도록 개선).
