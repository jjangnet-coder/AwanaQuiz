# 12개 시험장 동시 제출 누락 0% 보강 & E2E 고속화 계획서

## 1. 수정 목표
- **실전 12개 시험장 동시 제출 시 데이터 누락 0건(100% 저장)** 보장
- **E2E 전체 시뮬레이션 소요 시간 27분 → 약 3~5분**으로 단축 (클릭 속도 10배 향상 + 고부하 동시 제출 실전 검증)
- E2E 테스트가 실패한 제출을 `"제출 완료"`로 위장하지 않고 **실제 저장 성공 여부**를 엄격히 검증

---

## 2. 세부 수정 내역

### A. 시험장 점수 입력 자동 재시도 (`index.html`)
- `submitScores()`의 `fetch(GAS_URL, { method: 'POST', ... })` 구간에 **지수 백오프 + 랜덤 지터(Jitter) 자동 재시도** 추가:
  - 최대 **4회 자동 재시도** (총 5회 시도)
  - 대기 시간: 1차 `1.5~2.5초`, 2차 `3.0~4.5초`, 3차 `5.0~7.0초`, 4차 `7.5~10.0초`
  - 재시도 대상: 서버 락 혼잡(`잠금` / `혼잡`) 또는 네트워크 일시 오류
  - 재시도 중 로딩 문구 실시간 안내: `서버 혼잡 — 자동 재시도 중 (1/4)...`
  - 4회 재시도까지 모두 실패한 극단적 경우에만 기존 `"제출 실패"` 알림 표시 (그리드 데이터 보존)

### B. Google Apps Script 락 점유 시간 3~5배 단축 (`google-apps-script/Code.gs`)
- **`multiple` / `speed` / `written` 점수 저장 시 부분 범위(Partial Range) 쓰기 최적화**:
  - 기존: `최종집계` 시트 **1,376행 전체**를 읽고 1,376행 전체를 덮어쓰기.
  - 변경: `payload.records`에 포함된 단원들의 최소 행(`minRow`) ~ 최대 행(`maxRow`) 구간만 읽고 쓰기 (일반적으로 1개 조 약 20~25행 → 시트 쓰기량 **90%+ 절감**).
- **로그 시트 매 제출마다 호출하던 정렬 서식 API 3회 제거**:
  - `setHorizontalAlignment()` 3회 RPC 호출 제거 (로그 append는 `setValues()` 단 1회로 종결).
- *(※ `Code.gs` 수정분은 Apps Script 에디터에 붙여넣고 **새 버전으로 웹앱 배포** 1회 필요. 배포 전에도 A번 클라이언트 자동 재시도만으로 누락 방어 동작)*

### C. E2E 클릭 속도 10배 향상 & 진짜 저장 검증 (`test/e2e/simulate-12-rooms.spec.js`)
1. **클릭 속도 10배 향상 (기본 `10~35ms`, `SPEED_SCALE` 환경변수로 조절 가능)**:
   - 셀 클릭 간격: `100~350ms` → **`10~35ms`**
   - O→X 재클릭 간격: `80~200ms` → **`8~20ms`**
   - 교시 전환/탭 전환 대기: `400~900ms` → **`100~250ms`**
   - 전체 12개 시험장 완주 시간 **27분 → 약 3~5분**으로 단축 + 동시 제출 빈도 극대화!
2. **가짜 `제출 완료` 로그 제거 & 실제 저장 검증**:
   - 저장 대기 타임아웃: `20초` → **`90초`** (자동 재시도 포함 충분한 대기) + `.catch(() => {})` 제거.
   - `#loadingOverlay`가 사라지고 `#btnSubmit`이 `.state-saved` 또는 `disabled`가 되었는지 실제 검증.
   - 알림 모달 제목(`#modalTitle`)에 `'실패'` 또는 `'오류'`가 포함되면 즉시 실패(`throw new Error(...)`)로 집계해 **단 1건의 누락도 숨기지 않음**.
