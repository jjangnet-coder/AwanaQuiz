# [전수 조사 상세 수정계획서] 구글 스프레드시트 전체 18개 시트 탭의 모든 열 너비 및 정렬 전수 표준화

구글 스프레드시트에 존재하는 **모든 18개 시트 탭(기본 7개 탭 + 11개 공식 핸드북별 시상 탭)**의 **모든 컬럼(총 200개 이상의 열)**을 단 하나도 빠짐없이 전수 조사하여, 텍스트가 잘리거나 여백이 과도하지 않도록 최적의 너비(px)와 정렬 기준을 완전히 표준화합니다.

---

## 1. 정렬(Alignment) 전수 표준 규칙
- **헤더 1행 전체:** 무조건 **`가운데 정렬(Center)`**, **`굵은 글씨(Bold)`**, 연회색 음영(`배경색 #F1F5F9`)
- **식별 코드 / 짧은 텍스트 / 순번:** 무조건 **`가운데 정렬(Center)`**
  - 예: 참가자ID, 세션, 교실명, 교시, 학년, 조, 번호, 석차, 메달, 최고득점상, 접속코드
- **문항 판정 기호:** 무조건 **`가운데 정렬(Center)`** (1번~10번의 'O', 'X')
- **일반 텍스트:** 
  - `이름`, `기록관명`, `본부입력자`: **`가운데 정렬(Center)`** (한국어 3~4글자 이름의 시각적 안정성)
  - `교회명`, `핸드북`: **`가운데 정렬(Center)`**
  - `설명`, `비고`: **`좌측 정렬(Left)`**
- **숫자 점수 및 비율:** 무조건 **`우측 정렬(Right)`** (자릿수 맞춤)
  - 예: 필기점수, 객관식점수, 스피드점수, 총점, 비율값

## 3. 원클릭 포맷팅 함수 (`formatAllSheetsNicely()`) 제공 방식

- **데이터 보존:** 기존 입력된 점수, 선수 명단, 로그 기록 등 **어떠한 데이터도 손상시키지 않고 오직 서식/너비/정렬만 1초 만에 일괄 교정**합니다.
- `setup_sheets.gs`, `setup_test_data.gs`, `Code.gs`에 이 표준화 함수를 탑재하여 언제든 Apps Script 메뉴에서 클릭 한 번으로 실행할 수 있습니다.
- 초기화 스크립트 실행 시에도 이 18개 표준 규격이 자동으로 적용됩니다.

위 전수 조사 명세서에 대해 검토해 보시고 승인해 주시면 즉시 구현에 착수하겠습니다!
