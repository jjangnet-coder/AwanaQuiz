# 핸드북별 결과 표 열 너비 고정 & 최고득점자 모아보기(화면·인쇄) 전면 리디자인 계획서

## 1. 문제 원인 진단
1. **전체 시상 결과 조회 (`#hbAwardTable`)**: `table-layout: fixed`와 열별 고정 너비가 없어 핸드북을 바꿀 때마다 모든 열의 너비가 흔들리고, `핸드북` 열은 너무 넓고 `시험장` 열은 좁아 보임.
2. **최고득점자 모아보기 (화면)**: 11개 카드를 `4×3` `1fr`로 억지 확장해 단원 1~2명 아래로 카드의 80%가 텅 빈 공백으로 남고, SPARKS/T&T 구분도 없어 엉성해 보임.
3. **최고득점자 인쇄 (`printTopScorers`)**: 화면의 `height: 100%` 카드 HTML을 그대로 복사해 인쇄하면서 1번 카드가 A4 1페이지를 통째로 잡아먹고 2장으로 쪼개지는 버그 발생.

## 2. 수정 방안 (`admin/index.html`)

### A. 전체 시상 결과 조회 표 열 너비 고정 (`#hbAwardTable`)
- `table-layout: fixed;` 적용 + 14개 열 고정 너비 지정으로 **핸드북 변경 시 열 너비 흔들림 0px** 보장:
  - `No.`(`48px`), **`핸드북`(`128px`, 축소)**, `석차`(`56px`), `메달`(`86px`), **`시험장`(`88px`, 확대)**, `학년`(`52px`), `조`(`52px`), `번호`(`56px`), `교회명`(가변 `auto` + 말줄임), `이름`(`92px`), `필기`(`82px`), `객관식(오전)`(`92px`), `객관식/스피드(오후)`(`96px`), `최종총점`(`84px`).

### B. 최고득점자 모아보기 화면 전면 리디자인 — **SPARKS / T&T 2단 공식 명예의 전당 보드**
- 텅 빈 `4×3` 카드 그리드를 폐기하고, **좌측 SPARKS(5개 핸드북 · 레드 액센트) / 우측 T&T(6개 핸드북 · 그린 액센트)** 2단 패널 구조로 재설계.
- 각 핸드북 항목은 깔끔한 행 카드로 구성:
  - 좌측: 핸드북명 + 최고점수 골드 필 배지(`🏆 300점 · 1명`)
  - 우측/하단: 또렷한 수상자 칩(**이름** · 교회명 · `시험장 N조`) → 현장 호명 및 확인이 한눈에 가능하며 텅 빈 여백이 전혀 없는 균형 잡힌 밀도.

### C. 최고득점자 인쇄 전면 재작성 — **A4 세로 단 1장 공식 시상 호명표**
- 화면 `innerHTML` 복사 방식 완전 폐기 → `HQ_DATA`에서 직접 **A4 1장 전용 공식 표** HTML을 생성:
  - 헤더: `{대회제목} — 핸드북별 최고득점자 공식 명단` + 총 수상자 수 + 출력 일시
  - 본문: **SPARKS(5개) / T&T(6개)** 섹션 구분 + 공식 4열 표(`핸드북 | 최고점수 | 인원 | 최고득점자 (교회명 · 소속)`)
  - `@page { size: A4 portrait; margin: 12mm; }` 적용 → **11개 핸드북 전체가 여백 균형 있게 A4 단 1장에 완벽 출력**.
