## 1. 핵심 디자인 전략: "하얀 바탕이 좋을까? 두 화면을 분리할까?"

결론부터 말씀드리면, **하나의 브랜드 패밀리(폰트·라운드·상태색)를 공유하되, 사용 환경에 맞춰 두 화면의 시각적 톤을 명확히 분리**하는 것이 최적입니다.

| 구분 | 시험장 점수 입력 (`index.html`) | 본부 관리 포털 (`admin/index.html`) |
| :--- | :--- | :--- |
| **사용 환경** | 교실 형광등/자연광 아래 노트북·태블릿, 3시간 이상 연속 O/X 고속 클릭 | 본부석 대형 모니터에 종일 띄워두고 12개 시험장 진행 현황 모니터링·집계·인쇄 |
| **추천 테마** | **고대비 웜-라이트 (Warm Light Workspace)** | **딥 슬레이트 헤더 + 차분한 라이트 바디 (Pro Command Dashboard)** |
| **배경 전략** | 순백 도배 대신 `#F1F5F9`(차분한 쿨 그레이) 캔버스 위에 `#FFFFFF` 채점표 카드를 띄워 눈부심 최소화 | 상단 헤더를 `#0F172A`(딥 슬레이트 다크)로 눌러 시선 안정화 + 본문은 `#F1F5F9` 위 `#FFFFFF` 카드 |
| **핵심 목표** | **오입력 제로 & 23명 무스크롤 집중** (채점표가 화면의 85% 이상 주인공) | **3m 거리에서도 상태 0.5초 인지** (완료/진행/대기 색상 대비 + 버튼 위계 정리) |

## 2. 전수조사로 발견한 숨은 UI/코드 버그 6건 (함께 수정)

이번 줄 단위 전수조사에서 발견된 실제 결함들을 리뉴얼과 함께 일괄 수정합니다:

1. **`Pretendard` 웹폰트 미로드 (`index.html:32`, `admin/index.html:34`)**: CSS `font-family`에 `"Pretendard"`만 적혀 있고 실제 CDN `<link>`가 없어 Windows에서 투박한 `맑은 고딕`으로 폴백되고 있음 → Pretendard Variable CDN 로드 추가.
2. **본부 로딩 스피너 정지 버그 (`admin/index.html:1465`)**: `#hqLoadingOverlay`와 `syncScoresLightweight`가 `animation: spin`을 쓰지만 `<style>` 안에 `@keyframes spin`이 누락되어 스피너가 돌지 않음 → `@keyframes spin` 추가.
3. **스피드 퀴즈 잠금 셀 오인 위험 (`index.html:391-395`)**: `.quiz-cell.locked::after { content: "✕"; }`가 오답 `X`와 혼동될 수 있음 → 은은한 대각선 빗금(`repeating-linear-gradient`) + 중앙 점(`·`)으로 변경해 오답 `X`와 완벽히 분리.
4. **네이티브 `alert()` 1건 잔존 (`admin/index.html:2613`)**: `exportAllHandbooksToExcel()`에 브라우저 기본 `alert()` 잔존 → `showCustomAlert()`로 교체.
5. **인쇄 팝업 내 오버레이 중복 코드 (`admin/index.html:2599-2602`)**: `printTopScorers()` 템플릿 안에 `#hqLoadingOverlay` div가 잘못 들어가 있음 → 제거.
6. **`대회제목` 설정 연동 누락 & `@media print` 누락**:
   - `admin/index.html:2587, 3919, 3979, 4120` (인쇄물 제목), `index.html:1083` (하단 푸터)에 여전히 `2026-2027 AWANA 성경퀴즈대회`가 하드코딩됨 → `설정` 시트의 `대회제목` 동적 반영.
   - `admin/index.html:1292-1303` (`@media print`) 숨김 대상에 `#tab-handbook-awards` 추가.

## 3. 공통 디자인 시스템 (Design Tokens)

1. **타이포그래피**:
   - `Pretendard` Variable 웹폰트 적용 (`letter-spacing: -0.02em`)
   - 모든 점수·인원·석차·시간·퍼센트 요소에 `font-variant-numeric: tabular-nums` 적용 (숫자 흔들림 방지)
2. **컬러 팔레트 & 버튼 위계 정리**:
   - **이모지 대폭 절제**: 버튼·탭·헤더에 남발된 이모지(`📍`, `🔒`, `🔓`, `📤`, `🔄`, `🗑️`, `📡`, `💾`, `✏️`, `🔀`, `☀️`, `🌙`)를 제거하고 깔끔한 텍스트/상태 점(dot) 중심으로 정리 (메달/트로피 등 수상 상징만 유지).
   - **버튼 3단계 위계 확립**:
     - `Primary` (화면당 핵심 액션 1개만): `#1E293B` (본부) / `#2563EB` (시험장)
     - `Secondary` (새로고침, 인쇄, 취소 등 일반 액션): `#FFFFFF` 배경 + `#CBD5E1` 테두리 + `#334155` 텍스트
     - `Danger` (점수 초기화 등 파괴적 액션만): 평소 `#FEF2F2` 배경 + `#DC2626` 텍스트 (호버 시 강조). **`로그아웃`은 빨간색 Danger에서 차분한 Ghost/Secondary로 변경**해 초기화 버튼과 시각적 충돌 제거 (`admin/index.html:1624-1625`).
   - **SPARKS / T&T AWANA 공식 브랜드 컬러**:
     - **SPARKS (빨강)**: `#E11D48` (세련된 크림슨 레드) + 파스텔 `#FFF1F2` / 텍스트 `#BE123C`
     - **T&T (초록)**: `#059669` (세련된 에메랄드 그린) + 파스텔 `#ECFDF5` / 텍스트 `#047857`
     - (`index.html`의 `#clubBadge`와 `admin/index.html`의 `.theme-sparks` / `.theme-tnt` 시험장 카드 상단 라인 및 배지에 일관 적용)

## 4. 화면별 상세 UI 개선 사항

### A. 시험장 화면 (`index.html`)
1. **게이트웨이 로그인 모달 (`905-944행`)**:
   - 상단 컬러 액센트 바 추가, 이모지(`🏆`, `🔓`) 제거, 입력창 포커스 링 정리.
2. **상단 헤더 바 (`969-1036행`)**:
   - `📍 스팍스1 🔒` + `🔓 로그아웃`의 과한 이모지 제거 → 깔끔한 시험장 배지(`스팍스1`) + 가벼운 텍스트 버튼(`시험장 변경`).
   - `btn-secondary`(짙은 회색 배경 `185행`)를 깔끔한 화이트 아웃라인 버튼으로 변경.
3. **채점표 (`239-466행`)**:
   - 23명 무스크롤(`height: 31px`) 규격은 **100% 유지**.
   - `O` 셀(`#ECFDF5` / `#059669`), `X` 셀(`#FFF1F2` / `#E11D48`)로 대비는 높이고 눈 피로도는 낮춤 + 클릭 시 미세한 `transform: scale(0.95)` 피드백.
   - 잠금 셀(`.locked`)의 `✕` 문자를 제거하고 대각선 빗금 패턴으로 변경.

### B. 본부 관리 포털 (`admin/index.html`)
1. **딥 슬레이트 상단 바 (`50-124행`, `1606-1627행`)**:
   - 배경 `#0F172A`, 제목 `#FFFFFF`, `HQ ADMIN` 배지를 세련된 반투명 필(`rgba(255,255,255,0.12)`)로 변경.
   - 5개 탭 네비게이션을 다크 헤더 안에 1줄로 깔끔하게 통합 (활성 탭: `#FFFFFF` 배경 + `#0F172A` 진한 글씨).
   - 우측 액션: `새로고침` (다크 고스트), `대회 점수 초기화` (은은한 로즈 톤), `로그아웃` (다크 고스트)로 정리.
2. **대시보드 탭 (`1630-1710행`, `2695-2855행`)**:
   - 상단 4대 요약 카드에 미세한 그림자와 `tabular-nums` 적용.
   - 12개 시험장 카드(`.room-monitor-card`) 헤더에 **완료율 요약(예: `3/7 완료`)** 표시 및 교시 칩(`state-full`, `state-partial`, `state-empty`)의 가독성 강화.
3. **선수 관리 / 필기 채점 / 수상자 명단 / 핸드북별 시상 탭**:
   - 인라인 스타일(`style="..."`)을 공통 CSS 클래스로 정리해 5개 탭의 여백·테두리·버튼 크기를 하나로 통일.
   - `#resetScoresModalOverlay`(`1470행`)에도 `.custom-modal-card`와 동일한 상단 컬러 바·여백 규격 적용.
   - **주의**: `@media print` 인쇄 규격(`1275-1459행`)의 A4 고대비 흑백 레이아웃은 현장 인쇄용으로 최적화되어 있으므로 `대회제목` 동적 연동 외에는 기존 인쇄 규격을 안전하게 유지.
