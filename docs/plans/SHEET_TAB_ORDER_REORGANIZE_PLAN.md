# [수정계획서] 구글 스프레드시트 18개 탭 순서 자동 정렬 및 배치 최적화

## 1. 개요 및 원인 분석
- **현상:**  
  `setup_sheets.gs` 또는 `setup_test_data.gs` 실행 후 시트 탭 순서가 엉켜 `설정` 뒤에 `참가자명단`이 아닌 `행글라이더 1학년` 등 핸드북 시트가 먼저 배치됨.
- **원인:**  
  구글 스프레드시트의 `insertSheet(name)`는 기본적으로 **현재 활성화된 시트 바로 다음(앞쪽)**에 새 시트를 삽입하거나 기존 시트가 남아있는 위치에 그대로 머무릅니다. 
  기존 시트가 있는 상태에서 초기화 코드를 실행하면 시트 탭의 물리적 인덱스(순서)가 고정되지 않아 뒤섞이게 됩니다.
- **해결 방안:**  
  스프레드시트 API `ss.setActiveSheet(sheet); ss.moveActiveSheet(targetIndex);`를 활용하여 **18개 시트를 사용자가 원하시는 완벽한 공식 순서대로 1번부터 18번까지 강제 자동 재배치**하는 함수 `reorderAwanaSheets(ss)`를 구현하여 초기화 및 서식 적용 시 즉시 순서가 정리되도록 합니다.

## 3. 구현 내용 상세

### A. 탭 순서 자동 재배치 헬퍼 함수 추가 (`setup_sheets.gs`, `setup_test_data.gs`)
```javascript
/**
 * 18개 전체 시트 탭을 사용자가 지정한 공식 순서대로 물리적 위치 재배치
 */
function reorderAwanaSheets(ss) {
  const desiredOrder = [
    '설정',
    '참가자명단',
    '시간표',
    '객관식_로그',
    '스피드_로그',
    '필기_로그',
    '최종집계',
    '행글라이더 1학년',
    '행글라이더 2학년',
    '윙러너 1학년',
    '윙러너 2학년',
    '스카이스토머 2학년',
    '어드밴처1권 3학년',
    '어드밴처1권 4학년',
    '어드밴처2권 4학년',
    '챌린지1권 5학년',
    '챌린지1권 6학년',
    '챌린지2권 6학년'
  ];

  let currentPosition = 1;
  desiredOrder.forEach(name => {
    const sheet = ss.getSheetByName(name);
    if (sheet) {
      ss.setActiveSheet(sheet);
      ss.moveActiveSheet(currentPosition);
      currentPosition++;
    }
  });

  // 정렬 후 첫 번째 '설정' 시트를 활성화
  const firstSheet = ss.getSheetByName('설정');
  if (firstSheet) {
    ss.setActiveSheet(firstSheet);
  }
}
```

### B. 초기화 함수 연동
- `setupAwanaSheets()` 및 `setupAwanaTestData()` 실행 시 헤더와 데이터 작성 완료 후 `reorderAwanaSheets(ss)`를 호출하여 탭 순서를 단번에 1위~18위로 정렬.
- 독립 실행이 가능하도록 `reorderSheetsOnly()` 전용 실행 함수도 제공하여, 기존 데이터를 건드리지 않고 탭 순서만 즉시 정렬할 수도 있게 지원.
