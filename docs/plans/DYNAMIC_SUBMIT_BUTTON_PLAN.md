# [수정계획서 2차] 사용자 피드백 반영: 동적 교시 버튼 및 제출 상태 관리

## 1. 개선 아이디어 반영
* **사용자 제안:** 버튼 라벨을 **`[N교시] 점수 제출`** 로 적용
* **장점:** 
  - 단순히 "제출"이라고만 적혀 있는 것보다, 내가 지금 **몇 교시 시험 점수를 제출하고 있는지 한눈에 재확인(더블 체크)**할 수 있어 현장 실수를 100% 예방하는 최고의 아이디어입니다!

---

## 2. 세부 구현 계획

### ① 버튼 라벨의 동적 변경 (`index.html`)
* 교시가 선택되기 전: **`📤 점수 제출`**
* 교시가 선택되었을 때 (예: 1교시 선택 시): **`📤 1교시 점수 제출`**
* 교시가 4교시로 변경되었을 때: **`📤 4교시 점수 제출`**

### ② 제출 상태(미제출 vs 제출완료) 시각적 피드백
1. **미제출 상태 (채점 중이거나 수정되었을 때):**
   - 버튼 스타일: 선명한 주황색 계열 (`#f97316`)
   - 버튼 텍스트: **`📤 1교시 점수 제출 (미제출)`**
2. **제출 완료 상태 (중앙 시트에 성공적으로 동기화된 직후):**
   - 버튼 스타일: 차분한 녹색 계열 (`#16a34a`)
   - 버튼 텍스트: **`✅ 1교시 제출 완료`**
3. 다시 셀을 클릭하여 점수를 수정하면 ➔ 자동으로 **`📤 1교시 점수 제출 (수정됨)`** 주황색 버튼으로 즉시 복귀하여 재제출 필요성을 알림.

### ③ 교실/교시 전환 시 미제출 경고
* 기록관이 채점 입력을 해두고 제출 버튼을 누르지 않은 채 다른 교실이나 다른 교시를 선택하려고 할 때:
  - 브라우저 확인창: `"⚠️ 현재 교시의 채점 결과가 아직 중앙 서버로 제출되지 않았습니다. 제출하지 않고 이동하시겠습니까?"` 안내 팝업으로 실수 원천 차단.
