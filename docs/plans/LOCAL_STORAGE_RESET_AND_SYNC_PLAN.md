# [수정계획서] 로컬 캐시 전면 제거 및 커스텀 이탈 방지 경고 시스템 구축

## 1. 개요 및 배경
- **문제점:**
  - 브라우저의 `localStorage`에 채점 데이터(`GRID_STATE`)를 임시 저장하는 로직 때문에, 관리자가 구글 시트를 초기화(`setup_test_data.gs`)해도 웹 브라우저에는 과거 채점 데이터가 그대로 화면에 떠서 심각한 혼선 초래.
  - 퀴즈 대회 특성상 1개 조 시험은 5~10분 내에 완료되어 바로 제출되므로, 복잡하고 부작용이 많은 로컬 캐시를 유지할 실익이 없음.
- **방향성:**
  - **불필요한 채점 로컬 캐시(`awana_...`) 전면 제거** ➔ 오직 **구글 시트(중앙 서버)**가 단 하나의 절대적 기준(Single Source of Truth)이 됨.
  - 채점 도중 실수로 다른 교실/교시를 누르거나, 새로고침/페이지 이동을 시도할 때 발생할 수 있는 데이터 손실 위험은 **강력하면서도 정중한 `Custom Confirm` 경고 팝업**으로 완벽하게 방어.

---

## 2. 상세 수정 계획

### A. 채점 데이터 로컬스토리지 완전 제거
1. **`getStorageKey()`, `saveToLocalStorage()` 제거:**
   - 문항 클릭 시 로컬스토리지에 쓰던 작업 완전 중단.
   - 단, 편의를 위한 `awana_locked_room`(고정 교실)과 `awana_recorder_name`(기록관 성함)만 유지.
2. **`initGridAndRender()` 단순화:**
   - 로컬 캐시 복구 코드 전면 삭제.
   - 화면이 열릴 때 구글 시트의 최신 점수 상태에 따라:
     - 시트에 점수가 있으면 ➔ 시트 점수 로드 및 `[✅ 제출 완료]` 표시
     - 시트에 점수가 없으면 ➔ **언제나 100% 깨끗하고 투명한 빈 채점판**으로 렌더링.
   - 관리자가 시트를 리셋하면, 웹 앱 새로고침 시 모든 기기가 즉시 깨끗한 빈 상태로 동기화됨.

### B. 강력하지만 정중한 `Custom Confirm` 이탈 방지 시스템 구축
채점관(선생님)이 문항 O/X를 하나라도 입력한 상태(`작성중(in_progress)`)에서 실수로 화면을 벗어나려 할 때, 시스템이 친절하면서도 엄중하게 경고합니다.

1. **상황 1: 채점 중에 상단 [교실] 또는 [교시] 또는 [새로고침]을 클릭하여 이동하려 할 때**
   - 즉시 화면 전환을 멈추고 **경고 스타일 커스텀 모달** 팝업 노출:
   > **⚠️ 채점 데이터 미제출 안내**
   > 
   > 현재 **[스팍스1 / 1교시]** 조의 채점 점수가 아직 중앙 서버로 제출되지 않았습니다.
   > 
   > 지금 다른 화면으로 이동하시면 입력하신 채점 내용이 모두 사라집니다.
   > 
   > 정말로 작성을 취소하고 이동하시겠습니까?
   > 
   > **[계속 채점하기(취소)]** (강조) &nbsp;&nbsp;&nbsp;&nbsp; **[작성 취소하고 이동]** (경고 레드)

2. **상황 2: 브라우저 새로고침(F5) 또는 창 닫기 시도 시**
   - 브라우저 표준 `beforeunload` 이벤트 리스너를 연동하여 실수로 창을 닫거나 새로고침하는 행위를 원천 차단.

3. **커스텀 모달 UI 고도화 (`badge-type-danger` 스타일 추가):**
   - 경고 아이콘 배지를 붉은색(`🚨` 또는 `⚠️`)으로 강조하고,
   - 버튼 또한 실수 방지를 위해 **[계속 채점하기]**를 기본 파란색으로 안전하게 강조, **[작성 취소하고 이동]**은 붉은색 테두리 버튼으로 배치하여 실수 클릭 방지.
