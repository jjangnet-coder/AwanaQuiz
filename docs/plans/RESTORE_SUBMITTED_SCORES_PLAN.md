# [수정계획서] 제출 완료된 채점 데이터(O/X 및 점수) 복원 및 세션 상태 보존 방안

## 1. 현상 및 원인 분석
- **현상:** 점수기록관이 1교시 점수를 제출한 뒤, 2교시로 이동했다가 다시 1교시로 돌아오거나 새로고침했을 때 입력했던 O/X 채점표가 모두 빈칸으로 사라져 있는 문제.
- **원인:**
  1. **구글 시트에는 점수가 100% 정상 저장되어 있습니다.** (`객관식_로그`와 `최종집계` 시트에 80점, 70점 등 정상 기록 확인)
  2. 로컬스토리지 삭제 이후, 교시를 바꿀 때마다 실행되는 `initGridAndRender()` 함수가 **학생들의 채점판(`GRID_STATE`)을 무조건 빈칸(`''`)으로 덮어쓰고 버튼도 `[empty]`(미입력) 상태로 리셋**하고 있었습니다.
  3. 즉, **"이미 제출 완료된 교시로 다시 돌아왔을 때, 제출했던 채점 내용과 완료 상태를 복원해 주는 로직"**이 누락되어 있었습니다.

---

## 2. 해결 목표
1. **교시 간 자유로운 이동 시 완벽한 복원 및 수정 재제출 지원:**
   - 1교시 제출 완료 후 2교시를 채점하다가 다시 1교시를 클릭하면, **제출했던 O/X 채점 결과와 점수가 그대로 화면에 복원**되고 버튼도 **`[✅ 1교시 제출 완료]`** 녹색 상태로 표시됩니다.
   - **★ 수정 및 재제출 지원:**
     - 복원된 상태에서 채점관이 특정 셀(O/X)을 클릭하여 점수를 수정하면, 버튼이 즉시 **`[📤 1교시 점수 최종 제출 (수정됨)]`** 주황색 상태로 바뀌며, **언제든지 구글 시트로 수정된 점수를 덮어쓰기(재제출)할 수 있습니다!**

2. **시트 초기화 시 유령 데이터 잔류 방지 및 새로고침 철통 보호:**
   - 브라우저 영구 캐시(localStorage)를 쓰지 않고 현재 브라우저 세션 메모리(`SUBMITTED_SESSIONS_CACHE`)와 구글 시트의 실시간 점수(`MASTER_DATA.scores`)를 기반으로 판단하므로, 관리자가 시트를 리셋하면 새로고침 시 깨끗한 빈 상태로 열리는 원칙이 100% 유지됩니다.
   - **★ 새로고침 시 미제출 데이터 보호 경고 (작성 중 이탈 차단):**
     - 채점 입력 중(`in_progress` 또는 `ready`)일 때 상단 **[🔄 새로고침]** 버튼을 누르거나 키보드 `F5` / 브라우저 새로고침을 시도하면:
     - 🚨 **"현재 [1교시] 조의 채점이 아직 제출되지 않았습니다! 지금 새로고침하시면 작성 중이던 O/X 채점 데이터가 모두 사라집니다. 정말로 새로고침하시겠습니까?"** 강력한 경고 모달창이 뜨며, 기본 포커스는 안전한 **[계속 채점하기]**로 고정되어 실수를 원천 차단합니다.

## 3. 상세 수정 계획

### A. 세션 내 제출 데이터 보존 및 복원 구조 (`index.html`)
1. **메모리 세션 캐시 도입 (`SUBMITTED_SESSIONS_CACHE`):**
   - 점수 제출 성공 시(`saveCurrentSheet`):
     - 해당 조의 세션 식별키(`room_period_sessionName`)를 기준으로 **채점 결과(`GRID_STATE`)를 메모리에 보관**하고, 상태를 `'saved'`로 기록합니다.
     - `MASTER_DATA.scores`에도 방금 제출한 점수를 즉시 갱신합니다.
2. **화면 렌더링 시 자동 복원 (`initGridAndRender`):**
   - 교시를 선택하거나 세션을 바꿀 때:
     - **Case 1 (방금 브라우저에서 제출한 이력이 있는 경우):**
       - `SUBMITTED_SESSIONS_CACHE`에서 O/X 배열을 그대로 꺼내어 화면에 채우고, 버튼을 **`[✅ N교시 제출 완료]`** 상태로 렌더링.
     - **Case 2 (새로고침 등으로 캐시는 없으나 구글 시트에 이미 점수가 있는 경우):**
       - 구글 시트의 `MASTER_DATA.scores`에 해당 학생들의 점수가 이미 등록되어 있다면:
       - *"이 교시는 이미 중앙 서버에 제출 완료된 교시입니다."* 안내와 함께 총점을 화면에 표시하고 버튼을 **`[✅ N교시 제출 완료]`** 상태로 렌더링.
     - **Case 3 (시트에 점수가 전혀 없는 새 시험):**
       - 100% 깨끗한 빈 채점판으로 렌더링 및 `[📤 점수 제출]` 대기 상태.

### B. 새로고침 시 교실 프리패치 데이터 갱신
- 상단 **[🔄 새로고침]** 버튼을 누르면:
  - 현재 고정된 교실의 최신 점수와 명단을 다시 불러와 `ROOM_PREFETCH_CACHE`를 최신화하여 화면을 복원합니다.
