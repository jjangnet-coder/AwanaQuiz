# [상세 수정계획서] 교실 난독화 보안, 구글 테이블 변환 내구성 및 11개 핸드북 메달/시상 시트 구축

> **문서 관리 안내:** 본 문서는 사용자님의 피드백(교실 위치 조정, 테이블 변환 버튼 메커니즘, 11개 공식 핸드북 정확한 명칭, 교실별 메달 분출, 공동 석차 규칙, 유추 불가능한 보안 토큰)을 이전 계획서의 모든 세부 기술 내용과 온전히 통합하여 누락 없이 작성된 상세 개정판입니다.

## 1. 교실 접근 보안 강화: 난독화 토큰(Hash) + 교실 PIN 2중 보안

### A. 배경 및 우려 사항
- 기존 드롭다운 방식은 모든 기록관이 12개 모든 교실과 1~6교시의 점수/명단을 조회 및 수정할 수 있어 타 교실 오입력 위험과 공정성 시비가 발생할 수 있습니다.
- 단순 URL 파라미터(`?room=스팍스1`)는 사용자가 `스팍스2`로 주소창을 타이핑만 바꾸어 타 교실에 접근할 수 있는 치명적 허점이 있습니다.

### B. 상세 구현 방안
1. **유추 불가능한 전용 접속 키 (Hash Token):**
   - 각 교실별로 예측할 수 없는 난수 보안 토큰(또는 영숫자 키)을 부여합니다.
   - 예: `index.html?token=SP1-9482` 또는 `?key=c8f1a2`
   - 토큰 맵핑 테이블(대회 본부 및 스크립트 관리)에 일치하지 않는 임의의 파라미터 입력 시 화면 접근이 즉시 차단되고 오류 모달이 표시됩니다.
2. **교실 선택 잠금 (Lock):**
   - 올바른 토큰으로 접속하면 상단 **교실 드롭다운이 비활성화(Readonly)**되며 "📍 스팍스1 (고정 🔒)" 배지가 표시됩니다.
   - 기록관은 오직 배정된 교실의 교시(1~6교시)만 선택할 수 있습니다.
3. **2중 확인 장치 (교실 PIN 번호):**
   - 파라미터 없이 `index.html` 메인 링크로 접속한 경우:
     - 교실을 선택하면 **"해당 교실 PIN 번호 4자리"**를 묻는 커스텀 모달 팝업이 뜹니다.
     - 올바른 PIN을 입력해야만 해당 교실이 언락(Unlock)되며, 이후 교실 선택 드롭다운은 자물쇠(`🔒`)로 잠겨 타 교실 데이터를 볼 수 없습니다.
4. **설정 시트(`설정`)에서 교실별 PIN 관리:**
   - 대회 본부만 접근 가능한 `설정` 시트에 교실별 PIN(예: 스팍스1: `1101`, 스팍스2: `1102` 등 자유롭게 지정)을 정의하여 유연하게 운영할 수 있습니다.

## 2. 구글 시트 "테이블로 변환(Convert to Table)" 기능 완벽 대응

### A. 테이블 변환 버튼이 나타나는 원인 및 동작 원리
- **구글 시트의 자동 감지:** 구글 시트는 1행에 헤더가 있고 2행 이하에 연속 데이터가 있는 표준 표 형태를 감지하면, 사용자 편의를 위해 우측 상단이나 컨텍스트 메뉴에 **"테이블로 변환(Convert to Table)"** 추천 버튼/알림을 자동으로 띄웁니다.
- **버튼을 눌렀을 때 발생하는 변화:**
  - 헤더 스타일이 구글 기본 테이블 테마로 바뀌고, 각 열에 테이블 드롭다운 필터가 생성됩니다.
  - 구글 시트 내부적으로 데이터 영역이 일반 범위(`A1:L1377`)에서 구조화된 객체(`Table1`)로 승격됩니다.

### B. 테이블로 변환해도 100% 정상 작동하도록 방어 로직 구축 (Defensive Coding)
사용자가 호기심이나 실수로 "테이블로 변환" 버튼을 누르더라도 시스템이 전혀 망가지지 않도록 백엔드(`Code.gs`)를 방어적으로 작성합니다:
1. **실제 유효 행 필터링 (Trailing Blank Rows 방어):**
   - 테이블로 변환되면 `sheet.getLastRow()`가 테이블이 예약해 둔 빈 행까지 포함하여 실제 행보다 큰 값을 반환할 수 있습니다.
   - 따라서 1열(참가자ID 또는 교실명)이 실제로 존재하는 행만 필터링하여 정확한 유효 데이터 범위를 계산합니다.
2. **배열 메모리 일괄 처리 (In-Memory Array Processing):**
   - 테이블 구조화 참조(`Table[@컬럼명]`)에 의존하지 않고, 원시 2차원 값 배열(`getValues()`) 레벨에서 순수 자바스크립트로 데이터를 조작한 뒤 동일 크기 범위에 그대로 덮어쓰도록(`setValues()`) 설계하여 테이블 변환 상태에서도 완벽하게 호환됩니다.
3. **결론:** 구글 시트의 "테이블로 변환" 버튼을 누르셔도 아무런 문제가 없도록 완벽히 방어 처리됩니다.

## 3. 공식 11개 핸드북별 시상 시트 (교실별 메달 분출 지원)

### A. 정확한 공식 11개 핸드북 명칭 확정
1. `행글라이더 1학년`
2. `행글라이더 2학년`
3. `윙러너 1학년`
4. `윙러너 2학년`
5. `스카이스토머 2학년` *(※ 스카이스토머 1학년은 개설되지 않음)*
6. `어드밴처1권 3학년`
7. `어드밴처1권 4학년`
8. `어드밴처2권 4학년`
9. `챌린지1권 5학년`
10. `챌린지1권 6학년`
11. `챌린지2권 6학년`

### B. 시상 시트 컬럼 구성 (피드백 반영: 교실을 핸드북 오른쪽으로 배치)
대회 종료 후 **교실별로 메달을 신속하게 분출(배부)**할 수 있도록 `교실` 열을 `핸드북` 바로 오른쪽에 배치합니다:

| 컬럼 A | 컬럼 B | 컬럼 C | 컬럼 D | 컬럼 E | 컬럼 F | 컬럼 G | 컬럼 H | 컬럼 I | 컬럼 J | 컬럼 K | 컬럼 L | 컬럼 M | 컬럼 N | 컬럼 O |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **참가자ID** | **핸드북** | **교실** | **학년** | **조** | **번호** | **교회명** | **이름** | **필기** | **객관(오전)** | **객관/스피드(오후)** | **최종총점** | **석차** | **메달** | **최고득점상** |

- **교실 컬럼 자동 매핑:** 시간표 시트와 참가자(핸드북/조) 정보를 대조하여 해당 단원이 소속된 기본 교실(예: `스팍스1`, `스팍스3`, `티앤티2` 등)을 자동으로 매핑합니다.

## 4. 석차(순위), 메달 및 최고득점상 정밀 규칙 (엄격 준수)

### A. 공동 석차 규칙 (Dense / Standard Competition Ranking)
- **동일 총점 = 동일 석차:**
  - 예: 100점 동점자가 2명이면 둘 다 **1등**입니다.
  - 그 다음 점수(90점) 단원은 표준 대회 규정에 따라 **3등**이 됩니다 (1등, 1등, 3등...).
  - 점수가 입력되지 않았거나 결석/공석인 단원은 석차 및 시상 대상에서 제외됩니다.

### B. 메달 수여 및 동점자 컷오프 규칙 (금 30%, 은 40%, 동 30%)
1. **설정 시트 기반 비율 관리:**
   - `금메달_비율`: 기본 `0.3` (30%)
   - `은메달_비율`: 기본 `0.4` (40%)
   - `동메달_비율`: 기본 `0.3` (30%)
   - (비율은 `설정` 시트에서 관리자가 언제든 수정 가능)

2. **정밀 동점자 밀어내기 및 동메달 차감 알고리즘:**
   - 해당 핸드북 전체 유효 참가자 수: $N$ 명 (총점 내림차순 정렬)
   - **금메달 컷오프:**
     - 목표 금메달 인원: $Target_{gold} = \text{Round}(N \times 0.3)$
     - 만약 $Target_{gold}$ 등 단원의 점수와 동일한 동점자가 뒤이어 존재한다면(예: 30등과 31~35등의 총점이 동일), **35등까지 전원 금메달 부여** ($Count_{gold} = 35$).
   - **은메달 컷오프:**
     - 은메달 시작 등수: $Count_{gold} + 1$ 등 (예: 36등부터)
     - 목표 은메달 인원: $Target_{silver} = \text{Round}(N \times 0.4)$ (예: 40명)
     - 은메달 잠정 마감 등수: $Count_{gold} + Target_{silver}$ 등 (예: $35 + 40 = 75$등)
     - 만약 75등 단원과 동일한 동점자가 뒤이어 존재한다면(예: 76~78등), **78등까지 전원 은메달 부여** ($Count_{silver} = 43$).
   - **동메달 컷오프:**
     - 동메달 시작 등수: $Count_{gold} + Count_{silver} + 1$ 등 (예: 79등부터)
     - **금메달과 은메달이 동점자로 인해 늘어난 만큼, 동메달 대상 인원이 자동 차감**되어 나머지 인원에게 동메달 부여 (점수가 없는 결석자/공석자는 제외).

### C. 최고 득점상 규칙
- 해당 핸드북 전체 1등의 총점(최고 점수)과 동일한 총점을 기록한 **전원에게 `🏆 최고득점상` 표기** (단독 1위면 1명, 공동 1위 3명이면 3명 전원 수상).

## 5. 시간표 시트 정렬 기준 변경

- **현재 상태:** 1교시(전체 교실) ➔ 2교시(전체 교실) 순으로 나열되어 교실별 일정 파악이 번거로움.
- **개선 방향:** **`교실명(오름차순) ➔ 교시(오름차순)`** 순서로 완벽 정렬.
  - 예: 스팍스1(1~6교시) ➔ 스팍스2(1~6교시) ➔ ... ➔ 티앤티6(1~6교시)
