# [수정계획서] 제출 버튼 3단계 라이프사이클 상태 머신 개선

## 1. 현상 및 원인 분석
* **문제 현상:** 올려주신 캡처 화면처럼 점수를 아직 하나도 입력하지 않은 깨끗한 빈 표 상태인데도, 상단 버튼에 녹색 **`[✅ 5교시 제출 완료]`** 로 표시되는 어색한 상황 발생.
* **원인:**
  - 기존 로직이 단순히 `hasUnsavedChanges === false`이면 무조건 '제출 완료'로 간주하도록 2분법(이진 상태)으로 설계되어 있었음.
  - 즉, "아직 입력을 시작하지 않은 깨끗한 상태"와 "점수를 서버에 제출하고 난 직후의 상태"를 구분하지 못함.

---

## 2. 세부 수정 계획: 3단계 상태 머신 도입

버튼의 상태를 현장 흐름에 맞게 **3가지 상태**로 명확히 분기합니다:

| 상태 | 화면 상황 | 버튼 텍스트 | 버튼 색상 / 동작 |
| :--- | :--- | :--- | :--- |
| **① 입력 대기 (초기 상태)** | 교실/교시 선택 직후, 점수가 **전부 공란**인 상태 | **`📤 [N교시] 점수 제출`** | **기본 파란색** (점수가 없으므로 클릭 시 "입력된 점수가 없습니다" 팝업) |
| **② 채점 중 / 수정됨 (미제출)** | 셀을 클릭하여 `O`나 `X`가 **1개 이상 입력/수정**된 상태 | **`📤 [N교시] 점수 제출 (미제출)`** | **눈에 띄는 주황색** (제출 필요성 강조) |
| **③ 제출 완료** | 기록관이 제출 버튼을 눌러 **중앙 시트 전송 성공** 직후 | **`✅ [N교시] 제출 완료`** | **차분한 녹색** |

* **추가 연동 규칙:**
  - ③ '제출 완료' 상태에서 셀을 하나라도 다시 수정하면 ➔ 즉시 ② '미제출(주황색)' 상태로 전환되어 재제출 유도.
  - 전부 지워서 다시 완전 빈 표가 되면 ➔ ① '입력 대기(파란색)' 상태로 복귀.
