# AWANA 성경퀴즈대회 현장 UI/UX 개선 수정계획서

## 1. 개요 및 수정 배경
실제 1,376명 실전 데이터 연동 및 GitHub Pages 라이브 배포 후, 현장 점수기록관의 실제 입력 환경(노트북/태블릿 화면 크기, 직관적인 용어, 채점 속도 극대화)을 고려하여 프론트엔드 UI/UX를 전면 개편합니다.

---

## 2. 세부 수정 항목 명세

### ① 명칭 및 시각적 안내 직관화
* **시스템 타이틀 변경:** `Awana 성경퀴즈 현장 채점` ➔ **`AWANA 성경퀴즈대회 점수 입력 시스템`**
* **저장 버튼 라벨 변경:** `본부 시트 저장` ➔ **`💾 채점 완료 저장`**
* **상태 바 용어 정비:** `GAS 동기화 완료` ➔ **`연결 상태: 정상 (실시간 스프레드시트 연결됨)`**
* **클럽 배지 노출 조건 변경:** 교실을 선택하기 전에는 `SPARKS / T&T` 배지를 화면에서 숨김 처리하고, 교실 선택 시 해당 반의 클럽 배지만 동적으로 표출.

### ② 22~23명 무스크롤 압축 레이아웃 (반 전체 한눈에 보기)
* **문제점:** 반별 인원이 최대 20~23명인데, 기존에는 16명까지만 표시되어 매번 마우스/터치 스크롤이 필요함.
* **개선책:**
  * 상단 헤더, 컨트롤 패널, 세션 탭의 상하 여백(Margin/Padding)을 50% 이상 컴팩트화.
  * 테이블 행 높이를 `height: 29px`, 세로 패딩을 `2px`로 초슬림 압축.
  * 일반적인 13~15인치 노트북 및 태블릿(1080p 해상도)에서 **20~23명 전원이 세로 스크롤 없이 한 화면에 온전히 표시**되도록 최적화.

### ③ 객관식 문항별 '전원 정답(O)' 원클릭 일괄 채점 기능 (채점 속도 90% 단축)
* **현장 특성:** 객관식 퀴즈는 오답자보다 정답자가 훨씬 많으므로, 단원별로 하나씩 `O`를 누르는 방식은 비효율적임.
* **개선책:**
  * 테이블 헤더의 문제 번호(`1번`, `2번`... `8번`) 클릭 시 해당 문항의 **모든 학생이 일제히 `O`로 자동 채점**.
  * 기록관은 틀린 학생 셀만 찾아 좌클릭/우클릭으로 `X`로 변경하면 채점 완료.
  * 이미 전원 `O`인 상태에서 번호 헤더를 다시 누르면 전체 공백으로 토글 해제.
  * *참고: 스피드 퀴즈(T&T 오후)는 문항당 단일 정답자 제약(최대 1명)이 있으므로 이 일괄 기능은 비활성화.*

### ④ 세션별 '상태' 열 동적 분기
* **객관식 세션(오전/오후):** '상태' 열을 완전히 숨겨 가로 공간을 넓히고 시각적 혼선 제거.
* **스피드 세션(T&T 오후):** 퀴즈아웃/파울아웃 여부를 식별해야 하므로 '상태' 열을 자동으로 표출.
