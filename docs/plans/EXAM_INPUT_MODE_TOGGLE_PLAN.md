# 시험장 점수 입력 2가지 모드 (`O/X 문항별 채점` / `점수 직접 입력`) 추가 계획서

## 1. 목적
- `index.html`에서 현장 상황에 따라 **① O/X 문항별 클릭 채점 모드(기존)** 와 **② 총점 직접 입력 모드(신규)** 를 자유롭게 전환해 사용할 수 있도록 구현합니다.
- 선택한 모드는 `localStorage('awana_input_mode')`에 저장해 교시 전환·새로고침 후에도 유지합니다.
- 서버(`Code.gs`) 및 본부 관리 포털(`admin/index.html`)은 **수정 없이 100% 호환**됩니다.

---

## 2. 세부 구현 설계 (`index.html`)

### A. 모드 전환 토글 UI (`#subBarArea` 내부)
- 세션 탭(`객관식(오전)` / `스피드 퀴즈(오후)`) 우측에 깔끔한 세그먼트 토글 배치:
  - `☑️ O/X 채점` (기본값 `grid`) | `⌨️ 점수 직접 입력` (`direct`)
- **2중 안전 확인 팝업**:
  1. **미전송(작성·수정 중) 값이 있을 때**: 교시·세션 변경과 동일한 `showCustomConfirm(..., 'danger')` 이탈 경고 팝업 표시.
  2. **이미 O/X로 저장된 교시에서 `점수 직접 입력`으로 전환할 때**: *"이미 O/X 문항별로 저장된 교시입니다. [점수 직접 입력] 모드에서 점수를 수정·재전송하면 이후 다시 O/X 모드로 되돌릴 수 없습니다. 전환하시겠습니까?"* 확인 팝업 표시 후 승인 시에만 전환.

### B. `점수 직접 입력` 모드 테이블 & 규칙
- **컬럼 구성**: `NO · 핸드북 · 조 · 교회명 · 이름 · 점수 입력` (6열 심플 구성, 기존과 동일하게 `table { height: 100% }` 1/N 균등 분배로 **세로 스크롤 0%** 유지).
- **객관식 (오전 / 스팍스 오후)**:
  - 범위: **`0 ~ 80점`**, **`10점 단위`** (`step="10"`, `min="0"`, `max="80"`)
  - 초기값: **빈칸(`""`)** — 미입력 셀은 은은한 오렌지 테두리(`.is-unfilled`)로 강조, **출석 단원 전원 입력 완료 시에만 제출 가능**.
- **스피드 퀴즈 (T&T 오후)**:
  - 개인 최대점수: **`20 × Number(MASTER_DATA.settings['스피드_최대정답수'] || 3)`** (기본 `60점`), **`20점 단위`** (`step="20"`)
  - 초기값: **전원 `0` 자동 입력** (득점한 단원만 수정하고 즉시 제출 가능).
  - **조 합계 200점 상한 실시간 검증 (10문항 × 20점 = 최대 200점)**:
    - 안내바에 실시간 배지 표시: `조 합계: 140 / 200점 (득점 4명)`
    - 조 합계가 **`200점`을 초과**하면 배지가 빨간색 경고로 변하며 **`점수 전송` 버튼 비활성화 + 제출 차단**.
- **고속 키보드 입력 UX (필기 채점 탭과 동일)**:
  - 인풋 포커스 시 기존 숫자 자동 전체 선택(`this.select()`) → `0`을 지우지 않고 바로 `20`, `40`, `60` 입력 가능.
  - `Enter` / `↓` / `↑` 키로 다음·이전 단원 인풋 즉시 이동.
  - 범위 초과·단위 위반(예: 객관식 `15`, 스피드 `30`, `80`) 시 빨간 테두리(`.invalid`) 표시 및 제출 차단.
  - 공석(결번) 행은 `disabled` 고정.

### C. 대회 운영 무결성 정책 (모드 간 기존 점수 연동 & 역변환 차단)
1. **`O/X 모드`로 저장된 교시 → `직접 입력 모드`로 열기 (확인 팝업 후 허용)**:
   - 이미 저장된 총점(`MASTER_DATA.scores[id][scoreKey]`)을 입력칸에 그대로 불러와 확인·수정·재전송 가능.
   - 실제로 수정·재전송하면 새 로그는 `['직접입력']`으로 누적 저장되며(원본 O/X 로그는 시트에 감사 이력으로 보존), 그 시점부터 `O/X` 역변환이 잠김.
2. **`직접 입력 모드`로 저장된 교시 → `O/X 모드`로 전환 (원천 차단)**:
   - 해당 교시를 다시 열면 현재 기본 모드가 `O/X`였더라도 **자동으로 `점수 직접 입력` 모드로 표시**해 저장된 점수를 정확히 보여주며, **`☑️ O/X 채점` 전환 버튼을 잠금(클릭 시 안내 알림)** 처리해 빈 O/X 화면 혼동 및 오입력을 원천 차단.
3. **제출 확인 모달 요약 강화**:
   - 스피드 `직접 입력` 제출 확인 시 `득점 단원 N명 · 조 합계 X / 200점` 요약 표시.
