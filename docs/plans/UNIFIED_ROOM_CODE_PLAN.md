# [수정계획서] 교실 보안 코드(토큰/PIN) 단일화 및 스프레드시트 '설정' 시트 연동 관리

## 1. 개요 및 배경
- **문제점:** 
  1. 현재 URL 보안 토큰(`SP1-9482`)이 `index.html` 소스코드에 하드코딩되어 있어 본부가 변경하기 번거로움.
  2. 보안 토큰(`SP1-9482`)과 4자리 PIN(`1011`)을 따로따로 관리하면 본부 스태프가 기록관들에게 전달할 때 매우 헷갈리고 관리가 복잡해짐.
- **개선 목표:** 
  - **보안 토큰과 PIN을 하나로 완전 통합! ("교실 접속 코드")**
  - 스프레드시트의 **`설정`** 시트에서 교실별 접속 코드를 한눈에 확인하고 직접 수정할 수 있도록 연동.

---

## 2. 세부 구현 계획

### A. "교실 접속 코드(단일 코드)" 개념 도입
교실별로 복잡한 2가지 번호를 쓰지 않고, **단 1개의 고유 코드**만 발급합니다.
(본부에서 외우기 쉽고 타이핑하기 좋은 4~6자리 영숫자 권장)

**예시 (설정 시트의 기본값):**
- 스팍스1: `SP01` (또는 `1011`)
- 스팍스2: `SP02` (또는 `1022`)
- 스팍스3: `SP03` (또는 `1033`)
- ...
- 티앤티1: `TT01` (또는 `2011`)
- 티앤티2: `TT02` (또는 `2022`)
- ...

---

### B. 단일 코드로 2가지 접속 방식 동시 지원

1. **링크로 원클릭 접속할 때 (URL 파라미터):**
   - URL: `https://jjangnet-coder.github.io/AwanaQuiz/index.html?code=SP01` (또는 `?pin=1011`)
   - 기록관이 이 링크를 클릭하면:
     - 코드를 자동으로 대조하여 **"스팍스1 교실"로 즉시 잠금(Lock) 및 인증 완료**!
     - 팝업이나 추가 입력 없이 바로 채점 가능.
     - 주소창의 코드가 틀리거나 없으면 교실이 열리지 않음.

2. **메인 링크로 들어와 직접 입력할 때 (화면 모달):**
   - URL 파라미터 없이 접속하여 드롭다운에서 `스팍스1`을 누르면:
     - 팝업창: *"스팍스1 교실 접속 코드를 입력해 주세요."*
     - 링크에 쓰던 그 코드(`SP01` 또는 `1011`)를 입력하면 즉시 언락 및 교실 고정.

> **효과:** 본부에서는 각 교실에 **"링크 1개"** 또는 **"코드 1개"**만 전달하면 끝납니다!
