# [수정계획서 3차] 피드백 반영: 커스텀 팝업 시스템 및 버튼 라이프사이클

## 1. 반영할 사용자 피드백 분석
1. **버튼 초기 비활성화:** 교실 및 교시가 선택되기 전에는 제출 버튼이 클릭되지 않도록 **`disabled` (비활성화 상태 및 반투명 스타일)** 처리.
2. **수정 시에도 이탈 방지:** 초기 점수 입력뿐 아니라, 기존 점수를 **수정(정정)했을 때도 미제출 상태(`hasUnsavedChanges = true`)**로 감지하여 교실/교시 이동 시 동일하게 경고.
3. **브라우저 기본 팝업(alert/confirm) 완전 퇴출:** 촌스러운 브라우저 기본 흰색 팝업창을 완전히 없애고, **화면 정중앙에 애니메이션과 함께 뜨는 미려한 모던 커스텀 모달 팝업(Custom Modal System)**으로 100% 교체.

---

## 2. 세부 구현 계획

### ① 미려한 커스텀 팝업 컴포넌트 설계 (`Custom Modal System`)
* **스타일:**
  - 반투명 딤(Dim) 배경 오버레이 + 중앙 카드 애니메이션 (`fadeIn & scaleUp`)
  - 아이콘 배지 (알림 ℹ️, 경고 ⚠️, 성공 ✅, 확인 ❓)
  - 둥근 모서리, 부드러운 그림자, 명확한 [확인] / [취소] 버튼 디자인
* **유틸리티 함수 제공:**
  - `showCustomAlert(title, message, callback)` : 단순 안내용 (확인 버튼 1개)
  - `showCustomConfirm(title, message, onConfirm, onCancel)` : 확인/취소 선택용

### ② 버튼 비활성화 및 동적 상태 머신
* **초기 상태 (교실/교시 미선택):**
  - 텍스트: `📤 점수 제출`
  - 상태: `disabled` (클릭 불가, 회색 반투명)
* **교시 선택 후 (정상 로드 시점):**
  - 아직 변경사항 없음: `✅ [N교시] 제출 완료` (차분한 녹색) 또는 `📤 [N교시] 점수 제출` (파란색)
* **채점 셀 클릭 또는 전원O 등으로 점수 변경 발생 시 (신규 입력 및 수정 공통):**
  - 상태 플래그: `hasUnsavedChanges = true`
  - 버튼 스타일: 활성화 + 눈에 띄는 주황색 테마 (`#f97316`)
  - 텍스트: **`📤 [N교시] 점수 제출 (미제출)`**
* **제출 성공 시:**
  - 상태 플래그: `hasUnsavedChanges = false`
  - 버튼 스타일: 활성화 + 차분한 녹색 테마 (`#16a34a`)
  - 텍스트: **`✅ [N교시] 제출 완료`**

### ③ 미제출 이탈 방지 인터셉트 (신규 & 수정 공통)
* `roomSelect` 또는 `periodSelect` 변경 이벤트 발생 시:
  - `hasUnsavedChanges === true` 인 경우, 즉시 화면 전환을 멈추고 셀렉트박스를 이전 값으로 되돌림.
  - 화면 중앙에 커스텀 Confirm 모달 표출:
    - 제목: **`⚠️ 미제출 변경사항 안내`**
    - 내용: **`현재 [N교시] 채점 결과가 아직 중앙 서버로 제출되지 않았습니다.\n제출하지 않고 다른 교실/교시로 이동하시겠습니까?`**
    - [이동하기] 클릭 시 이동 진행, [취소] 클릭 시 현재 교시 유지.
